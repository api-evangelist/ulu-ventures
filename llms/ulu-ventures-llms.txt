# Ulu Ventures

> Ulu Ventures is a seed-stage venture capital firm in Palo Alto, California, founded by Miriam Rivera and Clint Korver. The firm applies decision analysis ("decision science") to seed investing and invests in diverse founder teams, having funded 200+ companies with 10 unicorns and 3 public companies across 14+ years. Ulu Ventures publishes no public API surface; this file indexes the firm's public web properties and the API Evangelist profile artifacts for this company.

Ulu Ventures grew from $3.5M in initial capital to a $66M first institutional fund and a $138M second fund. Seed-stage investing is the firm's exclusive focus.
